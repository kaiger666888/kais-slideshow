# kais-slideshow — 通用轮播制作管线

基于 [kais-movie-agent](https://github.com/kaiger666888/kais-movie-agent) 核心流程泛化的轻量级图文轮播管线。

## 功能

- 📝 **选题调研** — deep-research 深度调研 + kais-audience 受众测试
- 📄 **脚本设计** — 结构化分页脚本，8 种页面类型
- 🎨 **视觉生成** — AI 配图 / HTML 卡片 / 数据可视化
- ✅ **一致性保障** — 风格锁定 + 配色/字体统一检查
- 📤 **多格式输出** — PNG / PDF / MP4 视频轮播

## 适用场景

- 小红书图文轮播（知识卡片/教程/产品展示）
- 抖音图文合集
- 信息图表 / Infographic
- 知识总结 / 读书笔记
- 品牌产品展示

## 安装

```bash
git clone https://github.com/kaiger666888/kais-slideshow.git
cp -r kais-slideshow ~/.openclaw/workspace/skills/
```
